SYSTEM API REFERENCE

Comprehensive documentation for integrating with our architectural analysis and monitoring APIs.

Getting Started

Base URL: https://api.systemanatomy.com/v1

All API requests require authentication via Bearer token in the Authorization header.

Authorization: Bearer your_api_token_here

Authentication

POST /auth/token

Generate an access token for API access.

curl -X POST https://api.systemanatomy.com/v1/auth/token \
  -H "Content-Type: application/json" \
  -d '{
    "client_id": "your_client_id",
    "client_secret": "your_client_secret"
  }'

System Analysis

POST /analysis/system

Submit system metrics for architectural analysis.

curl -X POST https://api.systemanatomy.com/v1/analysis/system \
  -H "Authorization: Bearer your_token" \
  -H "Content-Type: application/json" \
  -d '{
    "system_id": "prod-web-01",
    "metrics": {
      "cpu_usage": 75.5,
      "memory_usage": 82.3,
      "response_time": 245,
      "error_rate": 0.02
    },
    "architecture": "microservices"
  }'

GET /analysis/{system_id}/report

Retrieve architectural analysis report.

curl -X GET https://api.systemanatomy.com/v1/analysis/prod-web-01/report \
  -H "Authorization: Bearer your_token"

Monitoring & Metrics

POST /metrics/ingest

Send monitoring metrics for processing.

curl -X POST https://api.systemanatomy.com/v1/metrics/ingest \
  -H "Authorization: Bearer your_token" \
  -H "Content-Type: application/json" \
  -d '{
    "timestamp": "2024-01-15T10:30:00Z",
    "service": "user-service",
    "metrics": [
      {"name": "http_requests_total", "value": 1250, "labels": {"method": "GET", "status": "200"}},
      {"name": "http_request_duration_seconds", "value": 0.145, "labels": {"method": "POST"}}
    ]
  }'

GET /metrics/query

Query historical metrics data.

curl -X GET "https://api.systemanatomy.com/v1/metrics/query?service=user-service&metric=http_requests_total&start=2024-01-01T00:00:00Z&end=2024-01-15T23:59:59Z" \
  -H "Authorization: Bearer your_token"

Alerts & Notifications

POST /alerts/webhook

Configure webhook endpoints for alert notifications.

curl -X POST https://api.systemanatomy.com/v1/alerts/webhook \
  -H "Authorization: Bearer your_token" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://your-app.com/webhooks/alerts",
    "events": ["system_degradation", "security_breach", "performance_anomaly"],
    "secret": "your_webhook_secret"
  }'

GET /alerts/history

Retrieve alert history and status.

curl -X GET https://api.systemanatomy.com/v1/alerts/history \
  -H "Authorization: Bearer your_token"

Error Codes

400 Bad Request - Invalid parameters
401 Unauthorized - Invalid token
403 Forbidden - Insufficient permissions
404 Not Found - Resource doesn't exist
429 Too Many Requests - Rate limit exceeded
500 Internal Server Error

Rate Limits

  • Analysis requests: 100 per hour
  • Metrics ingestion: 1000 per minute
  • Report generation: 10 per hour
  • Webhook notifications: Unlimited

Rate limit headers are included in all responses:

  • X-RateLimit-Limit: Maximum requests per window
  • X-RateLimit-Remaining: Remaining requests
  • X-RateLimit-Reset: Reset timestamp
